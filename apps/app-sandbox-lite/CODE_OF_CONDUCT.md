# YYC³ 团队行为准则（Code of Conduct）

> **_YanYuCloudCube_**
> _言启象限 | 语枢未来_
> **_Words Initiate Quadrants, Language Serves as Core for Future_**
> _万象归元于云枢 | 深栈智启新纪元_

---

## 我们的承诺

为营造开放、专业、协作的智能应用开发环境，YYC³ 团队（YanYuCloudCube）承诺：无论年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、个人形象、种族、宗教或性取向如何，每位参与者均可在本项目中免受骚扰，平等贡献。

我们以「**五高五标五化**」为共同信念：技术卓越、质量保障、效能提升——而这些都建立在**彼此尊重的协作**之上。

## 预期行为

参与本项目时，我们期望你：

| 行为 | 说明 |
| ---- | ---- |
| ✅ **以代码为准绳** | 讨论基于事实与代码证据，「不盲猜、不盲测、不盲从」 |
| ✅ **透明沟通** | 决策、风险、阻塞点及时同步，Context 完整可追溯 |
| ✅ **尊重差异** | 接纳不同经验水平的贡献者，耐心解答 |
| ✅ **专业反馈** | 代码评审对事不对人，给出可执行的改进建议 |
| ✅ **文档沉淀** | 遵循团队文档闭环规范，让知识可复用 |
| ✅ **保护敏感信息** | 不硬编码密钥、不泄露凭据、最小权限原则 |

## 不可接受行为

以下行为被严格禁止：

- 使用性化语言或意象、人身攻击或政治攻击
- 公开或私下的骚扰、威胁、人肉搜索
- 未经同意发布他人隐私信息（住址、邮箱、凭据等）
- 在专业场合发布色情、暴力或歧视性内容
- 故意提交恶意代码、后门、挖矿脚本或引入已知高危漏洞
- 明知故犯地绕过质量门禁（跳过测试、跳过 Hook、伪造验收结果）
- 其他在专业环境下可合理认定为不当的行为

## 职责与 scope

- **维护者**有责任澄清可接受行为标准，并对被认定为不当行为采取公正的纠正措施。
- 本准则适用于项目所有空间（代码库、Issue、PR、文档、会议、即时通讯群组），也适用于代表项目时的公开空间。

## 举报与执行

| 事项 | 渠道 | 响应时效 |
| ---- | ---- | -------- |
| 违规举报 | <admin@0379.email> | 48 小时内首次响应 |
| 安全相关违规（恶意代码/泄密） | <admin@0379.email>（标注 URGENT） | 24 小时内首次响应 |
| 申诉 | 同上，标注 APPEAL | 7 天内复审 |

所有举报将由项目维护者以**保密**方式处理。举报人信息不公开，不与被举报对象直接对质。经查实的违规将按情节采取：警告 → 临时禁_contrib → 永久移除 的阶梯处置。

**恶意举报**：如你受到或目睹不当行为，或受到本准则约束的不公正对待，请及时按上述渠道反馈。恶意、虚假举报本身亦构成不可接受行为。

## 归属

本准则改编自 [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html)，并结合 YYC³ 团队《AI 协同开发文档》与「五维驱动」理念进行本土化修订。
