## 三、关键修复成果（按风险层级）

### 🔴 高危 5 项 — 全闭环

1. **真实 API Key 出库**（.env.example → 占位符；历史清除建议 git filter-repo）
2. **Markdown 预览 XSS**（占位符抽离 + 整体转义 + URL 协议白名单）
3. **SVG 预览 XSS**（DOMPurify svg profile 净化）
4. **HTML 白名单放行 script/iframe**（白名单收紧，脚本诉求收敛专用通道）
5. **预览沙箱逃逸**（移除 allow-same-origin，封堵 API Key 窃取与同源 RCE 链）

### 🟠 中危 13 项 — 全闭环

Electron IPC 安全根模型（userData + 对话框授权路径 + DB 备份恢复校验，三端同步）、SHELL_OPEN 协议白名单、危险命令剔除、部署层收敛（127.0.0.1 默认 + CORS 白名单制 + Ollama 管理端点封禁）、CDN SRI、mock 认证空密码拒绝、**RequireRole 路由守卫**（10 个管理路由收敛 admin，三端落地）、操作日志真实身份、AI 缓存键 Unicode 安全、abort/重试语义修正、持久化列表上限、stale closure、流式缓冲、敏感导出确认。

### 🟡 低危 14 项 — 全处置

**安全加固**：LLM API Key 密文化（AES-GCM + 内存缓存 + 入口预热 + 旧键迁移）、内网端点 env 化收敛。
**逻辑修复**：假按钮真实现/禁用标注、SSID 防抖、onLine 订阅、effect 重挂、拖拽监听泄漏、同步队列上限、WS 告警持久化、fetch 超时、maxCacheSize 落地、importData 校验、损坏数据保护、审计真实时间戳。
