FIVE DIMENSIONS

五维驱动全域评估

基于 YYC³ 五维评估体系，对项目全链路进行时间、空间、属性、事件、关联五大维度综合评估

TIME

时间维 — 阶段节奏

Phase 1-4 按 3 周迭代周期推进，每阶段输出验证报告。模型微调数据持续积累，12 周内完成全链路闭环。关键路径：组件检索 → 页面组装 → 项目生成 → Figma 双向桥。

SPACE

空间维 — 资产布局

DGX Spark (Docker) 部署 Qwen3-14B 常驻 API；DGX Spark (FP8) 运行 Qwen3.6-27B 推理引擎；PostgreSQL + pgvector 存储 182K+ 向量知识库；NAS 存储模型权重与冷数据。

ATTR

属性维 — 组件分类

组件标签体系：domain (ai/medical/education) × style (cyberpunk/aurora/futuristic) × type (card/form/table/chart) × complexity (simple/medium/complex) × dependency (zero/radix/motion/three)。

EVENT

事件维 — 生成生命周期

用户请求 → 意图解析 → RAG 检索 → 模板匹配 → 主题注入 → 代码生成 → AST 验证 → TypeScript 编译 → 用户反馈 → 模板优化。全链路事件追踪与闭环反馈。

LINK

关联维 — 系统联动

AI 编程助手 ↔ @yyc3/cli (命令行) ↔ Figma Plugin (设计) ↔ PG 向量库 (检索) ↔ packages/* (组件/主题/底座)。六模块互联互通，形成完整智能开发生态。
