## 二、仲裁决策

### D1：@yyc3/ai 新包，4 组件全量包化（不裁断）
四件互为闭环（ModelProviderPanel 是两个 Modal 唯一消费方），view-context 桥接（D5）解除唯一硬卡点，不沿用 D7暂缓先例。

### D2：diagnostic-types 13 类型并入 core/src/types.ts
自包含零外部 import、core 零撞名，追加聚合段（携源文件头注释）。

### D3：websocket-types 5 新类型并入 core/types.ts，3 重定义删除
新增 ConnectionState / ThroughputPoint / SystemStats / WSMessage / WebSocketDataState；AlertLevel/AlertData/NodeData 用 core 已有同定义（逐字段已验）；app/types/websocket-types.ts 改具名 re-export 桥（`export type {...} from "@yyc3/core/types"`），app 内消费方零切换。

### D4：ViewState + Breakpoint 摘取并入 core/types.ts
layout-types.ts 中两段定义删除改 re-export 桥，其余 layout 类型不动。

### D5：view-context 上收 @yyc3/core + app 侧桥接
packages/core/src/view-context.ts（24L）；app/lib/view-context.ts × 3 改 `export * from "@yyc3/core/view-context"` → 60+ 消费方零切换。

### D6：状态 hooks 归 store，管道 hook 归 core
- useModelProvider → `@yyc3/store/use-model-provider`（provider-slice wrapper 归位）
- useAIDiagnostics → `@yyc3/store/use-ai-diagnostics`（诊断状态域）
- useWebSocketData → `@yyc3/core/use-websocket-data`（全局管道基建，与 use-persisted-state 同窗）
- store package.json：peerDependencies + `react: ^18 || ^19`，devDependencies 已有 @types/react
- 三端源 hooks 文件删除（包内单源）

### D7：@yyc3/ai 包结构
```
packages/ai/
├── package.json      exports: . + /aidiagnostics + /model-provider-panel + /add-model-modal + /provider-editor-modal
├── tsconfig.json     ES2022/bundler/strict/noEmit
├── DEV-GUIDE.md      随包迁移（P1 原件）
└── src/
    ├── index.ts      barrel（4 组件具名 export）
    ├── AIDiagnostics.tsx
    ├── ModelProviderPanel.tsx
    ├── AddModelModal.tsx
    └── ProviderEditorModal.tsx
```
- dependencies：@yyc3/core + @yyc3/store + @yyc3/ui（workspace:*）
- peerDependencies：react ^18 || ^19 + lucide-react ^1.8.0
- 包内引改写：GlassCard→@yyc3/ui、useModelProvider→@yyc3/store/use-model-provider、useAIDiagnostics→@yyc3/store/use-ai-diagnostics、useWebSocketData→@yyc3/core/use-websocket-data、ViewContext→@yyc3/core/view-context、types→@yyc3/core/types、useI18n 不变
- 三端 package.json：dependencies + `@yyc3/ai: workspace:*`（@yyc3/business 行后）

### D8：app 侧切引清单（含测试件）
- routes × 3：ModelProviderPanel + AIDiagnostics lazy → `import("@yyc3/ai/...")`
- useModelProvider 消费方 9 文件：SystemSettings/UnifiedModelManager/ConfigExportCenter × 3
- useAIDiagnostics 消费方 3 文件：ArchitectureAudit × 3
- useWebSocketData 消费方 21 文件：Layout/AIAssistant/FollowUpPanel/AlertRulesPanel/PatrolDashboard/RefactoringReport/ide-mock-data × 3
- 测试件：按 grep 实际清单切包路径（vi.mock 同步）
- 删源件：P1 modules/ai/ 6 文件（4 mv + index.ts 删 + DEV-GUIDE.md mv）、P3/P4 组件 × 8、三端 hooks × 9 → 共 23 源件

### D9：切换 pattern 纪律（偏差 #5/#8 固化）
- perl pattern 必含 `["']` 双引号类
- 同目录 `./` 与上层 `../` 深度同批枚举
- 临时脚本一律 /tmp
