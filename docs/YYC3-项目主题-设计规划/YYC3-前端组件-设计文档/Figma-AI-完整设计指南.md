## 🎨 设计系统概述

### 设计理念

YYC³ 设计系统融合了**现代简约**、**智能交互**、**多维导航**三大核心理念，创造出高效、直观、可扩展的设计体验。

#### 核心原则

1. **一致性**：统一的视觉语言和交互模式
2. **可扩展性**：模块化设计，支持快速扩展
3. **智能化**：AI 驱动的智能设计决策
4. **多维度**：支持多种导航方式和交互模式

### 设计风格

本设计系统支持多种设计风格：

- **液态玻璃风格**：透明、流动、现代
- **赛博朋克风格**：霓虹、科技、未来
- **未来科技风格**：简约、智能、高效
- **极光风格**：自然、流动、清新

### 1. 复式导航系统设计

#### 主导航设计

```
请设计一个主导航系统，要求：

1. 布局结构：
   - 顶部横向导航栏
   - 固定在页面顶部
   - 包含 5-7 个主导航项
   - 支持水平滚动（当导航项过多时）

2. 视觉样式：
   - 背景：白色半透明（rgba(255, 255, 255, 0.95)）
   - 毛玻璃效果：backdrop-filter: blur(10px)
   - 边框：底部 1px 实线，颜色 rgba(0, 0, 0, 0.1)
   - 阴影：无

3. 导航项样式：
   - 尺寸：高度 48px，宽度自适应
   - 内边距：12px 20px
   - 圆角：8px
   - 间距：4px
   - 字体：14px，字重 500
   - 颜色：
     * 默认：rgba(0, 0, 0, 0.6)
     * 悬停：rgba(0, 0, 0, 0.9)
     * 激活：#667eea，字重 600
   - 背景：
     * 默认：透明
     * 悬停：rgba(0, 0, 0, 0.05)
     * 激活：rgba(102, 126, 234, 0.1)

4. 激活状态指示：
   - 底部 2px 渐变线条
   - 渐变：从 #667eea 到 #764ba2
   - 圆角：2px

5. 图标：
   - 尺寸：20x20px
   - 位置：文本左侧，间距 8px
   - 悬停效果：放大 1.1 倍

6. 徽章：
   - 位置：右上角
   - 尺寸：最小宽度 18px，高度 18px
   - 内边距：0 6px
   - 背景：#ef4444
   - 文字：白色，11px，字重 600
   - 圆角：9px
```
