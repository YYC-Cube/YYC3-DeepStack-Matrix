## 🎨 设计理念

### 核心原则

卡片与模块设计融合了**模块化**、**灵活性**、**一致性**三大核心原则，创造出可复用、灵活、一致的组件系统。

#### 1. 模块化
- **独立封装**：每个卡片和模块都是独立的组件
- **可复用性**：组件可在不同场景下复用
- **可组合性**：组件可以组合成更复杂的界面

#### 2. 灵活性
- **可配置**：通过 props 配置组件行为和样式
- **可扩展**：支持插槽和自定义内容
- **可定制**：支持主题和样式定制

#### 3. 一致性
- **设计规范**：统一的设计规范和视觉语言
- **交互规范**：统一的交互模式和反馈机制
- **代码规范**：统一的代码风格和命名规范

### 适用场景

- **数据展示**：仪表盘、数据卡片、统计图表
- **内容展示**：文章卡片、产品卡片、图片卡片
- **功能模块**：工具卡片、设置卡片、操作卡片

## 📚 最佳实践

### 1. 卡片设计原则

#### 内容优先
- 保持卡片内容简洁明了
- 使用清晰的标题和描述
- 避免过度装饰

#### 视觉层次
- 使用字体大小和粗细建立层次
- 使用颜色区分重要信息
- 使用间距和留白增强可读性

#### 一致性
- 保持卡片样式的一致性
- 统一交互模式和反馈
- 遵循设计规范和指南

### 2. 性能优化

#### 懒加载
```typescript
const LazyCard = React.lazy(() => import('./Card'));

const CardGrid = ({ items }: { items: Item[] }) => {
```

#### 虚拟滚动
```typescript
import { useVirtualizer } from '@tanstack/react-virtual';

const VirtualCardGrid = ({ items }: { items: Item[] }) => {
  const parentRef = React.useRef<HTMLDivElement>(null);
  
  const virtualizer = useVirtualizer({
    count: items.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 400,
  });

  return (
    <div ref={parentRef} style={{ height: '100vh', overflow: 'auto' }}>
      <div style={{ height: `${virtualizer.getTotalSize()}px` }}>
        {virtualizer.getVirtualItems().map((virtualItem) => (
          <div
            key={virtualItem.key}
            style={{
              position: 'absolute',
              top: 0,
              left: 0,
              width: '100%',
              height: `${virtualItem.size}px`,
              transform: `translateY(${virtualItem.start}px)`,
            }}
          >
            <Card item={items[virtualItem.index]} />
          </div>
        ))}
      </div>
    </div>
  );
};
```
