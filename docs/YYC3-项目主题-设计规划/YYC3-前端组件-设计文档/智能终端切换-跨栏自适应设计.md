# 智能终端切换功能 - 跨栏自适应设计

## 📋 功能概述

### 核心设计理念

根据当前布局模式（编辑模式/预览模式），智能调整终端面板的显示范围：

- **编辑模式**：终端面板只在右栏显示（30%宽度）
- **预览模式**：终端面板跨越中栏+右栏（75%宽度）

---

## 🎨 布局模式

### 模式1：编辑模式

```
┌─────────────────────────────────────────────────────────────────┐
│  左栏(25%)  │  中栏(45%)  │  右栏(30%)  │
│             │             │             │
│  AI对话     │  文件资源    │  代码编辑器  │
│  面板       │  管理器       │             │
│             │             │  ┌─────────┐ │
│  用户输入    │  集成终端    │  │ 终端   │ │ ← 只在右栏
│             │             │  │ 面板    │ │
│             │             │  └─────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

**特点**：
- 三栏独立布局
- 终端切换符号在右栏顶部
- 终端面板只在右栏底部显示
- 终端宽度：右栏宽度（30%）

---

### 模式2：预览模式

```
┌─────────────────────────────────────────────────────────────────┐
│  左栏(25%)  │      合并区域(75%)      │

│  面板       │                           │

│             │  │                      │ │
```

**特点**：
- 左栏独立，中栏+右栏合并
- 终端切换符号在合并区域顶部
- 终端面板跨越整个合并区域底部
- 终端宽度：合并区域宽度（75%）

## 🔄 模式切换逻辑

### 状态管理

```typescript
interface LayoutMode {
  mode: 'edit' | 'preview';
  terminalVisible: boolean;
  terminalWidth: number;
}

const [layoutMode, setLayoutMode] = useState<LayoutMode>({
  mode: 'edit',           // 当前模式
  terminalVisible: false, // 终端是否显示
  terminalWidth: 0       // 终端宽度（根据模式自动计算）
});
```

### 模式切换函数

```typescript
const switchToEditMode = () => {
  setLayoutMode({
    mode: 'edit',
    terminalVisible: layoutMode.terminalVisible,
    terminalWidth: window.innerWidth * 0.3 // 30% 宽度
  });
};

const switchToPreviewMode = () => {
  setLayoutMode({
    mode: 'preview',
    terminalVisible: layoutMode.terminalVisible,
    terminalWidth: window.innerWidth * 0.75 // 75% 宽度
  });
};
```

### 终端宽度计算

```typescript
const getTerminalWidth = () => {
  const windowWidth = window.innerWidth;
  const leftColumnWidth = windowWidth * 0.25; // 25%

  if (layoutMode.mode === 'edit') {
    // 编辑模式：右栏宽度（30%）
    return windowWidth * 0.3;
  } else {
    // 预览模式：合并区域宽度（75%）
    return windowWidth - leftColumnWidth;
  }
};
```

## 💻 React 组件实现

### 智能终端面板组件

```tsx
import React, { useState, useEffect, useRef } from 'react';

interface SmartTerminalPanelProps {
  layoutMode: 'edit' | 'preview';
  isVisible: boolean;
  onToggle: () => void;
  onClose: () => void;
}

const SmartTerminalPanel: React.FC<SmartTerminalPanelProps> = ({
  layoutMode,
  isVisible,
  onToggle,
  onClose
}) => {
  const [terminalHeight, setTerminalHeight] = useState(200);
  const [isDragging, setIsDragging] = useState(false);
  const panelRef = useRef<HTMLDivElement>(null);

  // 根据模式计算终端宽度
  const getTerminalWidth = () => {
    const windowWidth = window.innerWidth;
    const leftColumnWidth = windowWidth * 0.25;

    if (layoutMode === 'edit') {
      return windowWidth * 0.3; // 编辑模式：30%
    } else {
      return windowWidth - leftColumnWidth; // 预览模式：75%
    }
  };

  const terminalWidth = getTerminalWidth();

  // 拖拽调整高度
  const handleMouseDown = (e: React.MouseEvent) => {
    e.preventDefault();
    setIsDragging(true);

    const handleMouseMove = (e: MouseEvent) => {
      if (panelRef.current) {
        const newHeight = window.innerHeight - e.clientY;
        setTerminalHeight(Math.max(100, Math.min(400, newHeight)));
      }
    };

    const handleMouseUp = () => {
      setIsDragging(false);
      window.removeEventListener('mousemove', handleMouseMove);
      window.removeEventListener('mouseup', handleMouseUp);
    };

    window.addEventListener('mousemove', handleMouseMove);
    window.addEventListener('mouseup', handleMouseUp);
  };

  return (
    <div
      ref={panelRef}
      className={`smart-terminal-panel ${isVisible ? 'active' : 'inactive'}`}
      style={{
        width: `${terminalWidth}px`,
        height: `${terminalHeight}px`,
        left: layoutMode === 'edit' ? '70%' : '25%', // 根据模式调整位置
        transform: isVisible ? 'translateY(0)' : 'translateY(100%)',
        transition: isDragging ? 'none' : 'transform 0.3s cubic-bezier(0.4, 0, 0.2, 1)'
      }}
    >
      {/* 终端标题栏 */}
      <div className="terminal-header">
        <div className="terminal-title">
          <span className="terminal-icon">🖥️</span>
          <span>终端</span>
        </div>
        <button
          className="terminal-close"
          onClick={onClose}
          aria-label="关闭终端"
        >
          ✕
        </button>
      </div>

      {/* 拖拽调整手柄 */}
      <div
        className="terminal-resize-handle"
        onMouseDown={handleMouseDown}
        aria-label="调整终端高度"
      />

      {/* 终端内容 */}
      <div className="terminal-content">
        <div className="terminal-prompt">$ npm install</div>
        <div className="terminal-prompt">$ npm run dev</div>
        <div className="terminal-prompt">$ </div>
      </div>
    </div>
  );
};

// 智能终端切换按钮
const SmartTerminalToggle: React.FC<{
  layoutMode: 'edit' | 'preview';
  isActive: boolean;
  onToggle: () => void;
}> = ({ layoutMode, isActive, onToggle }) => {
  return (
    <button
      className={`smart-terminal-toggle ${isActive ? 'active' : ''}`}
      onClick={onToggle}
      aria-label={isActive ? '隐藏终端' : '显示终端'}
      title={isActive ? '隐藏终端' : '显示终端'}
    >
      <span className="terminal-icon">🖥️</span>
    </button>
  );
};

export { SmartTerminalPanel, SmartTerminalToggle };
```

### 布局容器组件

```tsx
import React, { useState } from 'react';

interface LayoutContainerProps {
  children: React.ReactNode;
}

const LayoutContainer: React.FC<LayoutContainerProps> = ({ children }) => {
  const [layoutMode, setLayoutMode] = useState<'edit' | 'preview'>('edit');
  const [terminalVisible, setTerminalVisible] = useState(false);

  const switchMode = (mode: 'edit' | 'preview') => {
    setLayoutMode(mode);
    // 模式切换时，保持终端显示状态
  };

  return (
    <div className={`layout-container ${layoutMode}`}>
      {/* 左栏 - 固定25% */}
      <aside className="left-column">
        {/* AI对话面板 */}
        {/* 用户输入框 */}
      </aside>

      {/* 中栏和右栏容器 */}
      <div className="main-columns">
        {layoutMode === 'edit' ? (
          // 编辑模式：中栏和右栏独立
          <>
            <main className="middle-column">
              {/* 文件资源管理器 */}
              {/* 集成终端 */}
            </main>
            <aside className="right-column">
              {/* 代码编辑器 */}
              <SmartTerminalToggle
                layoutMode="edit"
                isActive={terminalVisible}
                onToggle={() => setTerminalVisible(!terminalVisible)}
              />
            </aside>
          </>
        ) : (
          // 预览模式：中栏和右栏合并
          <main className="merged-column">
            {/* 文件预览/编辑器 */}
            <SmartTerminalToggle
              layoutMode="preview"
              isActive={terminalVisible}
              onToggle={() => setTerminalVisible(!terminalVisible)}
            />
          </main>
        )}

        {/* 智能终端面板 */}
        <SmartTerminalPanel
          layoutMode={layoutMode}
          isVisible={terminalVisible}
          onToggle={() => setTerminalVisible(!terminalVisible)}
          onClose={() => setTerminalVisible(false)}
        />
      </div>
    </div>
  );
};

export default LayoutContainer;
```

## 🎓 总结

### 核心功能

1. **智能自适应**：根据布局模式自动调整终端宽度
2. **编辑模式**：终端在右栏（30%宽度）
3. **预览模式**：终端跨越中栏+右栏（75%宽度）
4. **平滑切换**：模式切换时终端自动调整
5. **状态保持**：终端显示状态在模式切换时保持不变
