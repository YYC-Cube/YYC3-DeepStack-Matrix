## 🎨 设计理念

### 核心原则

液态玻璃风格融合了**毛玻璃效果**、**液态流动**、**光影细节**三大核心元素，创造出通透、流动、未来感的视觉体验。

#### 1. 通透性
- **半透明背景**：使用 rgba 透明度创造层次感
- **多层叠加**：通过多层玻璃叠加营造深度
- **折射效果**：模拟光线穿过玻璃的折射

#### 2. 流动性
- **液态动画**：背景渐变缓慢流动
- **粒子浮动**：玻璃粒子在空间中漂浮
- **动态变化**：元素随时间缓慢变化

#### 3. 光影感
- **光泽扫过**：Shimmer 光泽效果
- **发光效果**：Glow 发光动画
- **阴影层次**：多层阴影营造立体感

### 适用场景

- **科技产品**：AI 助手、开发工具、数据可视化
- **创意应用**：设计工具、媒体编辑、艺术创作
- **社交平台**：现代社交、内容分享、社区互动

```css

### 2. 液态流动背景

#### 渐变光晕

  0% { background-position: 0% 50%; }

  100% { background-position: 0% 50%; }

```

#### 浮动粒子
