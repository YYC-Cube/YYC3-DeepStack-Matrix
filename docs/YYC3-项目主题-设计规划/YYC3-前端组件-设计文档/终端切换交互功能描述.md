# 终端切换交互功能描述

## 📋 功能概述

### 交互描述

在右栏（代码编辑器区域）的顶部工具栏中，有一个**终端切换符号**（🖥️ 或 ⌨️），点击该符号后，会在右栏底部**滑出/显示集成终端**。

---

## 🎨 视觉设计规范

### 1. 终端切换符号

#### 位置
- **位置**：右栏顶部工具栏
- **对齐**：右侧对齐
- **间距**：距离右边缘 16px

#### 符号设计
- **图标**：🖥️（终端图标）或 ⌨️（键盘图标）
- **尺寸**：24x24px
- **颜色**：
  - 默认状态：#94A3B8（灰色）
  - 悬停状态：#60A5FA（蓝色）
  - 激活状态：#3B82F6（深蓝色）

#### 交互状态
```
状态1：默认状态（终端隐藏）
- 图标：🖥️
- 颜色：#94A3B8
- 提示：显示终端（tooltip）

状态2：悬停状态
- 图标：🖥️
- 颜色：#60A5FA
- 光标：pointer
- 提示：显示终端（tooltip）

状态3：激活状态（终端显示）
- 图标：🖥️
- 颜色：#3B82F6
- 背景：#1E3A8A（浅蓝色背景）
- 提示：隐藏终端（tooltip）
```

## 💻 代码实现示例

### React 组件实现

```tsx
import React, { useState, useRef, useEffect } from 'react';

interface TerminalPanelProps {
  isVisible: boolean;
  onToggle: () => void;
  onClose: () => void;
}

const TerminalPanel: React.FC<TerminalPanelProps> = ({
  isVisible,
  onToggle,
  onClose
}) => {
  const [terminalHeight, setTerminalHeight] = useState(200);
  const [isDragging, setIsDragging] = useState(false);
  const panelRef = useRef<HTMLDivElement>(null);

  // 键盘快捷键
  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      if ((e.ctrlKey || e.metaKey) && e.key === '`') {
        e.preventDefault();
        onToggle();
      }
    };

    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, [onToggle]);

  // 拖拽调整高度
  const handleMouseDown = (e: React.MouseEvent) => {
    e.preventDefault();
    setIsDragging(true);

    const handleMouseMove = (e: MouseEvent) => {
      if (panelRef.current) {
        const newHeight = window.innerHeight - e.clientY;
        setTerminalHeight(Math.max(100, Math.min(400, newHeight)));
      }
    };

    const handleMouseUp = () => {
      setIsDragging(false);
      window.removeEventListener('mousemove', handleMouseMove);
      window.removeEventListener('mouseup', handleMouseUp);
    };

    window.addEventListener('mousemove', handleMouseMove);
    window.addEventListener('mouseup', handleMouseUp);
  };

  return (
    <div
      ref={panelRef}
      className={`terminal-panel ${isVisible ? 'active' : 'inactive'}`}
      style={{
        height: `${terminalHeight}px`,
        transform: isVisible ? 'translateY(0)' : 'translateY(100%)',
        transition: isDragging ? 'none' : 'transform 0.3s cubic-bezier(0.4, 0, 0.2, 1)'
      }}
    >
      {/* 终端标题栏 */}
      <div className="terminal-header">
        <div className="terminal-title">
          <span className="terminal-icon">🖥️</span>
          <span>终端</span>
        </div>
        <button
          className="terminal-close"
          onClick={onClose}
          aria-label="关闭终端"
        >
          ✕
        </button>
      </div>

      {/* 拖拽调整手柄 */}
      <div
        className="terminal-resize-handle"
        onMouseDown={handleMouseDown}
        aria-label="调整终端高度"
      />

      {/* 终端内容 */}
      <div className="terminal-content">
        <div className="terminal-prompt">$ npm install</div>
        <div className="terminal-prompt">$ npm run dev</div>
        <div className="terminal-prompt">$ </div>
      </div>
    </div>
  );
};

// 终端切换按钮
const TerminalToggle: React.FC<{
  isActive: boolean;
  onToggle: () => void;
}> = ({ isActive, onToggle }) => {
  return (
    <button
      className={`terminal-toggle ${isActive ? 'active' : ''}`}
      onClick={onToggle}
      aria-label={isActive ? '隐藏终端' : '显示终端'}
      title={isActive ? '隐藏终端' : '显示终端'}
    >
      <span className="terminal-icon">🖥️</span>
    </button>
  );
};

export { TerminalPanel, TerminalToggle };
```

## 📚 使用文档

### 用户指南

#### 如何显示终端
1. 点击右栏顶部的 🖥️ 图标
2. 或使用快捷键 `Ctrl + `` ` ``

#### 如何隐藏终端
1. 点击终端标题栏的 ✕ 按钮
2. 或再次点击 🖥️ 图标
3. 或使用快捷键 `Ctrl + `` ` ``

#### 如何调整终端高度
1. 将鼠标移动到终端顶部边框
2. 光标变为上下箭头时
3. 按住鼠标左键拖拽调整高度

#### 快捷键
- `Ctrl + `` ` ``：显示/隐藏终端
- `Ctrl + L`：清屏
- `↑` / `↓`：浏览命令历史
- `Ctrl + C`：中断命令
