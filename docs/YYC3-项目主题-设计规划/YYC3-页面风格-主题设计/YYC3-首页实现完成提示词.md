## 🔧 故障排除指南

### 常见问题及解决方案

#### 音效问题
```
问题：音效不播放
原因：
1. 浏览器不支持Web Audio API
2. 音效未启用
3. 音量设置为0

解决方案：
1. 检查浏览器兼容性
2. 确认音效已启用：soundEffects.isEnabledState()
3. 调整音量：soundEffects.setMasterVolume(0.5)
```

#### 动画问题
```
问题：动画卡顿
原因：
1. 系统性能不足
2. 动画过于复杂
3. 未启用GPU加速

解决方案：
1. 检查系统性能设置
2. 减少动画复杂度
3. 启用GPU加速：transform: translateZ(0)
```

#### 意图识别问题
```
问题：意图识别不准确
原因：
1. 关键词配置不当
2. 置信度阈值过高
3. 上下文分析不足

解决方案：
1. 调整关键词配置
2. 降低置信度阈值
3. 增加上下文分析深度
```

#### 响应式问题
```
问题：移动端显示异常
原因：
1. 媒体查询设置不当
2. 触控区域过小
3. 字体大小不合适

解决方案：
1. 检查媒体查询断点
2. 增大触控区域（最小44px）
3. 调整字体大小（最小14px）
```
