> **YYC³ 四端统一 UI 基础件库** — shadcn/radix 同源 49 件 + brand 件（GlassCard/YYC3Logo/EmptyState），Tailwind 语义 token 体系。

## ✨ 特性

- 深路径导入（`@yyc3-deepstack/ui/button`）为首选，barrel 仅供便捷聚合
- cjs + esm + dts 三格式产物，通配导出映射 dist 同构路径
- react/react-dom 为唯一 peer（^18 || ^19），radix/recharts 等全部外置

## 🚀 快速开始

```bash
pnpm add @yyc3-deepstack/ui
```

```tsx
import { Button } from "@yyc3-deepstack/ui/button";
import { Card, CardHeader, CardTitle } from "@yyc3-deepstack/ui/card";
import { GlassCard } from "@yyc3-deepstack/ui/brand/GlassCard";
```
